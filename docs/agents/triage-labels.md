# Triage labels

The skills speak in five readiness roles; this repo uses the same names as labels.

| Role / label      | Meaning                                                              |
| ----------------- | -------------------------------------------------------------------- |
| `needs-triage`    | The owner has not evaluated it yet                                   |
| `needs-info`      | Waiting on the reporter                                              |
| `ready-for-agent` | Scope, choices and acceptance criteria settled; an agent can take it |
| `ready-for-human` | Needs the owner: direction, cost or a call only they can make        |
| `wontfix`         | Will not be actioned                                                 |

Only `wontfix` exists so far; create the others with `gh label create` on first use.
